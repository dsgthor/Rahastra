# Rahastra - Zero-Knowledge File Sharing
# 
# This file lists the requirements for Rahastra.
# Since Rahastra is a client-side application that runs entirely in the browser,
# there are no traditional Python/Node.js dependencies.
#
# Requirements are listed by category for clarity.

# =============================================================================
# BROWSER REQUIREMENTS
# =============================================================================

# Modern web browser with the following API support:
# - Web Crypto API (for encryption/decryption)
# - File API (for file handling)
# - Drag and Drop API (for file selection)
# - Clipboard API (for copy functionality)
# - Web Share API (optional, for native sharing)

# Supported Browsers:
# - Chrome/Chromium 60+
# - Firefox 57+
# - Safari 11+
# - Edge 79+

# =============================================================================
# DEVELOPMENT TOOLS (Optional)
# =============================================================================

# For local development with live reload:
# npm install -g live-server
# Or use Python's built-in server:
# python -m http.server

# For code formatting and linting (if desired):
# npm install -g prettier
# npm install -g eslint

# =============================================================================
# EXTERNAL DEPENDENCIES (CDN)
# =============================================================================

# The following external libraries are loaded via CDN:
# - qrcode-generator@1.4.4 (from cdnjs.cloudflare.com)
#   Used for generating QR codes for easy mobile sharing

# CDN URL: https://cdnjs.cloudflare.com/ajax/libs/qrcode-generator/1.4.4/qrcode.min.js

# =============================================================================
# DEPLOYMENT REQUIREMENTS
# =============================================================================

# Static File Hosting:
# - Any static file hosting service (Netlify, Vercel, GitHub Pages, etc.)
# - Web server capable of serving HTML, CSS, and JavaScript files
# - HTTPS support (required for Web Crypto API)

# No Server-Side Requirements:
# - No database needed
# - No server-side runtime (Node.js, Python, PHP, etc.)
# - No environment variables or configuration files

# =============================================================================
# OPTIONAL ENHANCEMENTS
# =============================================================================

# For enhanced development experience:
# - Live reload server (live-server, serve, etc.)
# - Code editor with HTML/CSS/JS support
# - Browser developer tools for debugging

# For production deployment:
# - Content Security Policy (CSP) headers
# - Proper MIME type configuration
# - Gzip/Brotli compression for assets
# - HTTPS/TLS certificate

# =============================================================================
# SYSTEM REQUIREMENTS
# =============================================================================

# Client-Side (User):
# - Modern web browser with JavaScript enabled
# - Minimum 1GB RAM for large file processing
# - Stable internet connection for file upload/download

# Development:
# - Any operating system (Windows, macOS, Linux)
# - Text editor or IDE
# - Web browser for testing
# - Optional: Node.js for development tools

# =============================================================================
# SECURITY REQUIREMENTS
# =============================================================================

# Runtime Security:
# - Secure context (HTTPS) for Web Crypto API
# - Same-origin policy compliance
# - Content Security Policy headers (recommended)

# Browser Features Required:
# - Web Crypto API support
# - Secure random number generation
# - AES-GCM encryption support
# - PBKDF2 key derivation support

# =============================================================================
# NOTES
# =============================================================================

# This requirements.txt file is informational only.
# Rahastra is designed to run entirely in the browser without
# any server-side dependencies or installation requirements.
#
# To run Rahastra:
# 1. Download the HTML file
# 2. Open in a modern web browser
# 3. Start sharing files securely!
#
# For development:
# 1. Clone the repository
# 2. Serve files using any static file server
# 3. Open in browser and start developing
